# MGMT1003 期末复习

一个单文件的网页复习工具，覆盖 MGMT1003（Management, People and Organisations）Week 1–11 的全部内容。不需要安装任何东西，打开 HTML 文件就能用，手机电脑都可以。

## 怎么用

- **在线**：开启 GitHub Pages 后，直接访问仓库的 Pages 网址（入口是 `index.html`）。
- **离线**：下载 `MGMT1003复习.html`，双击打开。只有字体需要联网，没网也能正常用。

进度（做题记录、错题、闪卡熟练度）保存在浏览器本地，换浏览器或清缓存会丢失，建议固定用一个。

## 功能

| 模块 | 内容 |
|---|---|
| 总览 | 考试倒计时、各周做题进度和正确率 |
| 边练边学 | 按讲义顺序排列的 152 个考点、689 道题。每题先给知识点和解题规则，答完给逐步解题过程。不用先看笔记，直接做 |
| 笔记要点 | 每周 14 条核心要点；219 个概念，每个有一句话解释、一个例子、一个比喻，可跨周搜索 |
| 闪卡 | 概念闪卡，三级熟练度，不会的卡会很快再出现 |
| 分题练习 | 按周、按题型（判断 / 单选 / 匹配 / 简答）练习，即时解析 |
| 模拟考试 | 30 分钟快速版或 120 分钟完整版，题目从各周均匀抽取，交卷后按周、按题型出成绩 |
| 错题本 | 做错的题自动收集，可一键重做 |

题目是英文（与考试一致），解析是中文。

## 目录结构

```
复习软件/
├─ index.html            生成物：GitHub Pages 入口
├─ MGMT1003复习.html      生成物：本地双击打开（与 index.html 相同）
├─ artifact.html         生成物：claude.ai 在线版（无 html 骨架）
├─ app.template.html     网页源码（界面与逻辑，不含数据）
├─ build.ps1             校验题库并把数据内嵌进模板，生成上面三个文件
├─ data/
│  ├─ w01.json … w11.json        每周的要点、概念、判断题、单选题、匹配题、简答题
│  └─ learn/w01.json … w11.json  “边练边学”的考点与题目
└─ docs/                 题库格式与编写规范
```

## 修改题目后重新生成

在 PowerShell 里运行：

```powershell
& ".\build.ps1"
```

脚本会检查每个 JSON（选项数、答案范围、布尔值、必填字段等），有问题会直接报错并指出位置；通过后重新生成三个 HTML 文件。

- 改某周的题目或概念：编辑 `data/wNN.json`，格式见 `docs/题库格式说明.md`。
- 改“边练边学”的考点或题目：编辑 `data/learn/wNN.json`，格式见 `docs/边练边学编写说明.md`。
- 改界面：编辑 `app.template.html`。

## 说明

- 题库依据课程讲义编写，解析经过格式校验，但未逐题人工审校。发现错误欢迎提 issue 或直接改 JSON。
- 考试倒计时的日期写在 `app.template.html` 的 `EXAM_AT` 常量里，请以 Canvas 上的正式通知为准。
