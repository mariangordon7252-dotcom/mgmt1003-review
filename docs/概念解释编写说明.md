# 概念"一句话 + 例子 + 比喻"补充说明

给 `data\wNN.json` 里 `concepts` 数组的每一个概念，追加三个字段（放在 `defZh` 之后）：

| 字段 | 内容 | 要求 |
|---|---|---|
| `one` | 一句话解释 | 中文，一句话，≤40 个汉字左右；说清"它是什么/核心判断标准"，可保留关键英文术语。不要照抄 defZh 的符号堆砌（"+""→"），要读起来像人话。 |
| `eg` | 一个例子 | ≤50 字；具体、可想象。优先用该周笔记里出现的案例（公司、研究、数字）；笔记里没有就用大家熟悉的真实公司/日常职场场景。不要编造统计数字。 |
| `like` | 一个形象的比喻 | ≤35 字；以"像……"开头，生活化、一眼能懂，并且比喻要准确对应概念的关键特征（不要只是好玩）。 |

示例：
```json
{"term": "Scalable", "zh": "可扩张", "def": "...", "defZh": "...", "one": "客户和收入能成倍增长，而人手、场地和成本不用同比例增加。", "eg": "订餐 App 用户从 1 万涨到 10 万，服务器多花点钱即可；一家咖啡馆要翻倍客流就得多开店多招人。", "like": "像印书：第一本最贵，之后每多印一本几乎不花钱。"}
```

操作规则：
- 每个概念在文件里占一行。用 Edit 工具逐行修改：把该行结尾的 `"}` 改成 `", "one": "...", "eg": "...", "like": "..."}`。不要改动任何其他字段、题目或格式。
- 字符串里不要出现未转义的英文双引号 `"`；需要引号时用中文引号「」或“”。
- 全部改完后用 PowerShell 校验：`[IO.File]::ReadAllText('<路径>',[Text.Encoding]::UTF8) | ConvertFrom-Json` 不报错，且每个 concept 都有 one/eg/like。
