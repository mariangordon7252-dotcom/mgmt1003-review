# 题目中文对照：翻译说明

练习和“边练边学”里的题目和选项可以切换显示中文对照（模拟考试不显示）。翻译放在 `data/zh/wNN.json`，按题目 ID 对应，原题库不动。

## 文件格式

```json
"w4-mcq-0": {"en": "英文题干（自动生成，别改）", "enOptions": ["A","B","C","D"], "q": "中文题干", "options": ["中文A","中文B","中文C","中文D"]}
```

只填 `q` 和 `options`。`en` / `enOptions` 是生成脚本抄来的英文原文，用来核对，不要改。判断题和案例分析题没有 options。

## 翻译要求

1. **忠实**：意思和英文完全一致，不加提示、不加解释、不暗示答案。英文题干里没说的话，中文也不说；判断题的错误说法照样翻成错误说法。
2. **通顺**：像中文考卷那样自然，不要逐词硬翻。
3. **术语**：课程术语第一次出现时写成「中文（English）」，比如「社会惰化（social loafing）」「基本归因错误（fundamental attribution error）」；人名、理论名、模型名、缩写保留英文（Herzberg、LPC、MUM effect、HEXACO、CVF）。选项如果本身就是一个术语，写「中文（English）」，让学生能把中文和英文选项对上。
4. **数字、人名、公司名**原样保留。
5. 字符串里不出现英文双引号 `"`；引号用「」。
6. 案例分析题（essay）要整段翻译，保留段落意思和问题要求。

## 工具

```
node tools/zh-skeleton.js w04     # 生成/补全骨架；题库改了以后重跑，会保留已有翻译、清空原文变了的那几题
node tools/zh-check.js w04        # 校验：每题都有中文、选项数一致、原文和题库一致
```

`build.ps1` 会把 `data/zh/` 一起打包进网页；某题没有翻译时，切换中文也只显示英文。
