# 解析改写说明：让知识点解析和题目解析更简洁易懂

目标读者是一个准备闭卷考试、第一次学管理学的本科生。现在的解析像压缩过的课堂笔记（大量 `=`、`+`、`→`、`；`、英文缩写堆在一起），读起来费劲。改成**像同学讲给你听的大白话**。

## 要改的字段（其他一律不动）

| 位置 | 字段 | 怎么改 |
|---|---|---|
| `tf[].exp` | 判断题解析 | 第一句直接说清为什么对/为什么错（把正确的说法讲出来）；如果题目考的是一个常见混淆点，再加一句点破。**≤45 字**。 |
| `mcq[].exp` | 选择题解析 | 第一句说清正确选项为什么对；如果有一个很容易选错的干扰项，用一句话说它为什么不对。不要只重复答案。**≤60 字**。 |
| `concepts[].one` | 一句话解释 | 一句完整的话，说清“它是什么 / 核心判断标准”。**≤35 字**。 |
| `concepts[].eg` | 例子 | 具体、可想象，一眼看出和概念的对应。**≤45 字**。 |
| `concepts[].like` | 比喻 | 以“像……”开头，生活化，并且比喻要对应概念的关键特征。**≤30 字**。 |

`q`、`options`、`answer`、`a`、`term`、`zh`、`def`、`defZh`、`summary`、`match`、`essay` 全部保持原样，一个字符都不要改。

## 文风规则

1. **用完整的句子**，不要符号串。禁止用 `=`、`+`、`→`、`≠`、`vs` 来代替动词；`；` 最多出现一次。
   - 改前：`方面多且重叠少 = 高；属性在多方面重复出现会降低 self-complexity；可能是压力下的 cognitive buffer。`
   - 改后：`一个人的自我面向越多、彼此越不重复，自我复杂性就越高，压力来时更不容易被一件事击垮。`
2. **英文只留考试会考的术语本身**（如 Conscientiousness、sensemaking、MUM effect），其余用中文说。英文术语第一次出现时顺带给中文意思，例如“基本归因错误（fundamental attribution error）”。不要让一句中文里夹三个以上英文词。
3. **先讲结论，再讲原因**。读者看第一句就应该知道答案为什么是这样。
4. **数字和研究结论只能来自原解析或笔记**，不要新增统计数字、人名、年份；原解析里有的数字（如 r = .22、70%）要保留。
5. 不要出现“课件案例”“见 Lecture”这类指向性的话，直接把内容说出来。
6. 字符串里不要用未转义的英文双引号 `"`，需要引号用「」。

## 改前改后示例

**判断题**
- 题：A person with high emotional stability will score high on neuroticism.（False）
- 改前：`两者方向相反：High Emotional Stability = Low Neuroticism。`
- 改后：`情绪稳定性高的人，神经质（Neuroticism）得分是低的，这两个词说的是同一条线的两端。`

**选择题**
- 题：员工一周迟到三次，经理直接断定“他就是不负责任”，没查是不是交通或排班的问题。
- 改前：`解释他人行为时高估人格、低估情境 = 基本归因错误。应先问：是否经常发生、其他情境是否也如此、是否有特殊事件、其他人同条件下是否也迟到。`
- 改后：`经理把迟到全归到性格上，没考虑交通、排班这些情境因素，这就是基本归因错误。正确做法是先问：他平时也这样吗？别人遇到同样情况会不会也迟到？`

**概念**
- 改前 one：`自我方面越多、彼此重叠越少，自我复杂性越高，可能在压力下起缓冲作用。`
- 改后 one：`一个人的自我面向越多、彼此越不重复，自我复杂性就越高。`
