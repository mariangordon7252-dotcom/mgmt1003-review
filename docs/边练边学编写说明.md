# “边练边学”题库编写说明（data\learn\wNN.json）

这是一个**通过做题来学知识点**的模式：学生不先看笔记，直接按考点顺序做题。每道题先展示考点和“怎么用这个知识点”，答完展示“这道题是怎么用这个知识点解出来的”。目标是读完解题过程就等于学会了这个知识点。

## 文件格式

看现成的示例：`E:\MGMT1003\复习软件\data\learn\w01.json`（里面已经有 Lecture 1 的第 1 个考点，格式以它为准）。

```json
{
  "week": 3,
  "points": [
    {
      "id": "w03-p01",
      "title": "考点中文名",
      "titleEn": "English name",
      "kp": "知识点本身：一两句完整的中文，说清它是什么。关键英文术语保留。≤120 字",
      "howTo": "解题规则：看到题干里的什么线索，就选什么。要具体到能照着操作。≤110 字",
      "items": [
        {"type": "mcq", "q": "English question, exam style", "options": ["A", "B", "C", "D"], "answer": 2,
         "how": ["第一步：指出题干里的关键线索（引用原文词组）。", "第二步：套用规则，得出答案。", "第三步（可选）：最容易错选的那个选项为什么不对。"]},
        {"type": "tf", "q": "English statement", "a": false,
         "how": ["正确的说法是什么。", "题目把哪个词换掉了，所以是 False。"]}
      ],
      "recap": "一句话小结，≤75 字，是学生做完这个考点后应该记住的那一句。可以用「A → B」这种口诀式写法。"
    }
  ]
}
```

## 考点怎么划分

1. **按讲义里的出现顺序**排列考点。讲义文本在 `C:\Users\18374\AppData\Local\Temp\claude\C--Users-18374--claude-spares-spare-Rgc33O\843b445e-c2ef-45ac-b685-06402e7b3a88\scratchpad\txt\`（L1–L3 用 L1.txt/L2.txt/L3.txt，L4–L11 用 D4.txt…D11.txt）。
2. `E:\MGMT1003\复习软件\data\wNN.json` 里的 `summary`（14 条）是这一讲的必考要点清单，**每一条都必须被某个考点覆盖**；`concepts` 是术语表，用来确认术语和定义。
3. 每讲 **9–14 个考点**。一个考点 = 一个能用一条规则解题的知识单元。太大的要拆（比如 Big Five 拆成“五个维度各是什么”和“哪个维度最能预测绩效”），太小的合并。
4. 考试会考的比较和区分（A ≠ B、常见误区、数字结论）必须有专门的考点或专门的题。

## 题目怎么出

- 每个考点 **3–5 道题**，判断题和单选题混合，按从易到难排：先一道直接辨认，再一两道情境应用，最后一道区分干扰概念或考易错点。
- 题目用**英文**，和考试一致，多用具体情境（a manager…、a team…、a company…），少用“Which of the following is true”。单选题 4 个选项，干扰项要是课程里真实存在的相近概念，不要凑数。
- 可以改编 `data\wNN.json` 里已有的 tf/mcq 题，但改编的不要超过三分之一，`how` 必须新写。
- 数字、人名、研究结论**只能来自讲义**；讲义里没有的不要编。

## `how` 怎么写（最重要）

- 2–4 步，每步一句话，**≤80 字**。读者看完就知道“下次看到这种题怎么做”。
- 第一步永远是**指出题干里的线索**，引用题干原词（用「」括起来）。
- 第二步是**套规则得出答案**。
- 如果有一个很容易选错的选项，用一步说它为什么不对。
- 直接了当：不要“我们可以看到”“值得注意的是”之类的铺垫；不要重复题干；不要讲这个考点无关的内容。
- 文风和 `E:\MGMT1003\复习软件\data\BRIEF-simplify.md` 一致：完整句子，不用 `=`、`+`、`→`、`≠` 代替动词，英文只留考试术语本身。

## 技术要求

- `id` 格式 `wNN-pKK`（两位数），全文件唯一。
- 字符串里不出现未转义的英文双引号 `"`，引用用「」。
- 用 Write 工具一次写出整个文件（w01 除外：保留已有的第 1 个考点，在后面追加）。
- 写完运行校验：`powershell -NoProfile -ExecutionPolicy Bypass -File "C:\Users\18374\AppData\Local\Temp\claude\E--MGMT1003\843b445e-c2ef-45ac-b685-06402e7b3a88\scratchpad\validate-learn.ps1" wNN`，把报告里的问题改到零。它还会列出 summary 里哪些要点没被任何考点的 kp/题目覆盖到（按关键词粗略匹配）——逐条确认，确实没覆盖的要补。
